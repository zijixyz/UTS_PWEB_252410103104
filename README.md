Pada project kali ini, saya membuat sebuah Aplikasi Web Simulasi Login dan Pengelolaan Data yang responsif.
Aplikasi ini dibangun menggunakan framework Laravel murni dengan arsitektur MVC, dan menggunakan Blade Templating Engine untuk tampilannya tanpa bantuan template luar.
Untuk temanya, saya memilih Sistem Pengelolaan Inventaris Komputer (PC). Di dalamnya, saya mendemonstrasikan bagaimana data username bisa terbawa dari halaman login ke dashboard dan profil, serta bagaimana data array daftar perangkat PC ditampilkan secara dinamis di halaman pengelolaan.
